- **极艾简约**：餐饮包厢预约 SaaS（纯 To B · 订阅制）——几乎独立负责全产品

## 使用

- 本地打开：直接浏览器打开 `index.html`
- 在线访问：启用仓库的 GitHub Pages（Settings → Pages → Deploy from a branch → main / root）
