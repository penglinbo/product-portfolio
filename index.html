极艾简约 · 餐饮包厢预约

替代中小餐饮商户的纸质台账，打通「预约 → 管理 → 续费」，让小微商户零门槛用上数字化。

我的角色：几乎独立负责全产品 —— 需求梳理 · 原型设计 · 迭代落地 · PRD 与验收
产品思考链 · 从问题到验证
背景与问题

小微餐饮还靠本子记预约：漏记、撞单、客户资料散乱，老板离店就失控。

目标用户

单店/连锁餐饮老板与员工：要简单、不培训即用，成本敏感。

核心方案

极简预约 + 三角色权限 + 试用续费闭环，小程序即开即用。

验证落地

v1.x 功能全量上线，含支付与 AI 语音；后台运营闭环跑通。

权限与数据隔离

三角色各见所需：员工只见本人客户，管理员看全店，销售员管多门店。数据天然防抢单、防泄露。

  • 电话脱敏展示（138****8888）
  • 他人记录可看不可删

试用-续费商业闭环

新门店固定天数免费试用，到期前在「列表 + 我的」双触点提醒，三档套餐促成付费。

  • 基础 ¥999 / 专业 ¥1999 / 企业 ¥3999
  • 未续费不可继续使用

统计与后台治理

包厢使用率、午/晚时段、热门客户排行支撑经营决策；平台后台覆盖商户、订单、反馈全链路。

  • 操作日志审计 · 续费状态跟踪
  • AI 模块可配置（语音识别）

To B 平台能力 · 小程序 + PC 后台

薪茸工 · HR 与无卡发薪

在存量灵活用工平台（商户 / 代理商 + 打工者）上新增 HR 模块，让「招人 → 到岗 → 发薪 → 对账」双端闭环，钱发得规范、可追溯。

我的角色：负责 V2.0 新增 HR 模块 —— 需求文档 · 流程设计 · 原型与验收
产品思考链 · 从问题到验证
背景与问题

灵活用工人员流动快、发薪靠手工转账：记录乱、易漏发错发，劳资纠纷无据可查。

目标用户

商户 HR / 代理商：批量管理在岗人员并按时合规发薪；打工者要能确认自己到账。

核心方案

员工全生命周期管理 + 无卡发薪状态机 + 双端协同，用流程和规则兜住资金风险。

验证落地

PRD v1.0 成为研发依据，双端功能开发完成、进入测试验收。

员工全生命周期

手动 / 扫码 / Excel 三种录入，草稿核对后再提交；在职名单按任务项目聚合，档案、调岗、离职、合同提醒齐备。

  • 未分配任务项目禁止提交
  • 合同到期（≤7/15/30 天）提醒

无卡发薪状态机

制单 → 复核 → 放款全程状态机管理，驳回 / 失败可重提或扣回；一期仅开放付掌柜（无卡）通道。

  • 关键操作二次确认
  • 失败重提 / 错发扣回闭环

双端协同与资金安全

员工主数据以服务端为准，小程序 / PC 状态实时同步；乐观锁防重复打款，三级黑名单拦截风险人员。

  • 操作审计（人 / 时间 / IP）
  • 平台仅汇总，不碰资金

关键产品决策

用状态机兜住资金风险

发薪是资金敏感操作。我坚持用状态机 + 二次确认 + 乐观锁把"发错钱、重复发"变成流程上不可能，而不是依赖事后人工补救。

关键产品决策

一期通道收口

先只开放付掌柜（无卡）通道，微信 / 支付宝置灰且后端拒单。降低资金渠道复杂度，先把流程验证跑顺，再谈扩渠道。
